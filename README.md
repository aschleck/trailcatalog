# Trailcatalog and trails.lat

This repository hosts two applications that help people get outdoors.

* [Trailcatalog](https://trailcatalog.org) organizes OpenStreetMaps trail relations into a
  searchable catalog. Data is updated nightly.
* [trails.lat](https://trails.lat) is a trip planner for on- and off-trail adventures. Users have
  access to an extensive catalog of imagery and tools to plan their trips.

## Corgi

This uses my JS framework [Corgi](https://github.com/aschleck/corgi/tree/main/js/corgi). I think
it's cool and I hope you do too.

## S2

This project depends on Google's
[S2 Geometry Library](https://github.com/google/s2-geometry-library-java) and we host an S2 and
Z/X/Y cell viewer at [https://s2.trailcatalog.org](https://s2.trailcatalog.org). Left-click to
toggle cells, right-click to see cell information.
